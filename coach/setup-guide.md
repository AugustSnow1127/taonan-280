# 桃南 280 教練｜設定與使用說明（給騎士）

## 一、建立 claude.ai Project（賽前一週內完成）

1. 用電腦打開 claude.ai，左側點「Projects」→「Create Project」。
2. 名稱填：`桃南 280 教練`。
3. 打開 Project 右側的「Instructions」（自訂指令），把 `instructions.md` 全文貼進去，存檔。
4. 在「Project knowledge」上傳 `race-plan.md`。
5. 手機安裝 Claude App 並登入同一個帳號，確認看得到這個 Project。
6. 試用一次：在 Project 裡開新對話，傳一張隨便的回報卡截圖＋碼錶照片，確認回覆是口語、看得懂的三段式指令（現在做／接下來／原因）。
7. 確認對話設定裡「網路搜尋」是開啟的（10/30 賽前會議要查天氣）。

> 大會緊急電話公布後，記得填進 `race-plan.md` 第 1 節的 TODO，再重新上傳。

## 二、設定 BSC200「教練頁」

1. 手機打開 iGPSPORT App → 裝置 → BSC200 → 資料頁（Data Page）設定。
2. 新增一頁（或改一頁），放 8 個欄位，順序如下：

| 位置 | 欄位 |
|---|---|
| 1 | 目前時間 |
| 2 | 總距離 |
| 3 | 總時間（含停） |
| 4 | 騎乘時間 |
| 5 | 總均速 |
| 6 | 圈均速（沒有這個欄位就改用「圈時間」） |
| 7 | 圈平均踏頻 |
| 8 | 圈距離 |

3. 同步到碼錶，確認字夠大、拍得清楚。
4. 確認「自動分圈」關閉，只用手動按 Lap。
5. 確認路線 GPX 已載入。

## 三、比賽當天每一站的流程

只在停車時做，騎車時絕對不要碰手機。

1. 車停好，先按碼錶 **Lap**（這樣「圈」＝剛騎完的那一段）。
2. 打開比賽網頁 → 「比賽當天：回報教練」→ 按「📍 定位並產生回報卡」。
3. 截圖回報卡。
4. 切到碼錶「教練頁」，拍一張照片。
5. 在 Project 的同一個對話裡，傳截圖＋照片，再用語音輸入說：腿幾分（1–10）、肚子、哪裡痛、心情、這段吃喝了什麼。
6. 照教練第 1 行的指令做：停多久、吃喝什麼、下一段騎多快。

> 整場用同一個對話，教練才看得到前面幾站的趨勢。

> 全程單騎，不跟集團。若教練說會「非正式完賽」（21:00 後才到），照樣安全騎完，並在下一站先聯絡回程接送或查好交通（回程車最晚 21:00 從鹿耳門發車，未確認）。

## 四、10/30 賽前會議（晚上）

1. 在 Project 開新對話，命名「比賽日」。
2. 說：「開賽前會議，請查明天沿海天氣和風向，調整每段目標時速和停靠計畫。」
3. 確認教練給的表格，有問題就問。
4. 10/31 早上（約 03:30）在同一個對話回報：幾點睡、睡幾小時、早餐吃了什麼、裝備和車燈有沒有充飽。
5. 比賽時繼續用這個對話回報。

## 五、電力建議

| 裝置 | 建議 |
|---|---|
| 手機 | 出發前 100%；開省電模式；關閉不需要的 App 與背景定位；只在停車時開螢幕 |
| 碼錶 BSC200 | 前一晚充滿；280 km 約 16 小時，若續航不夠，在 CP2 用行動電源補電 |
| 頭燈／尾燈 | 前一晚充滿；白天關燈省電，17:00 後的停靠點再打開 |
| 行動電源 | 至少 10,000 mAh，帶好線材；每次停車順手幫手機充 |
| 網頁 | 回報卡需要定位；停車時才開，按完就關 |
